# 班级座位管理器

基于 Svelte 5、TypeScript、Vite 和 ExcelJS 的纯前端排座工具。所有名单和座位数据都在浏览器本地处理，不需要账号、后端或远程 API。

## 运行

```sh
pnpm install
pnpm dev
```

如果终端没有直接启用 pnpm，可使用 `corepack pnpm` 代替 `pnpm`。

```sh
pnpm check
pnpm test
pnpm build
pnpm preview
```

测试使用 Node.js 22.18+（推荐 Node.js 24）的内置 TypeScript 支持。构建产物位于 `dist/`，可以部署到静态网站。ExcelJS 在首次导出时按需加载，不访问远程服务。

## GitHub Pages 部署

推送到 `main` 或手动运行 GitHub Actions 中的 `Deploy to GitHub Pages` 工作流，会自动安装依赖、检查类型、运行测试、构建并部署 `dist/`。

- 仓库 **Settings → Pages → Build and deployment → Source** 应选择 **GitHub Actions**。
- 当前自定义域名为 `gseats.unoflow.org`，由 `public/CNAME` 随构建发布；Pages 设置中的 Custom domain 也应填写此域名，并确认 DNS 仍指向 GitHub Pages。
- Vite 使用相对资源路径，兼容自定义域名及 `/seats/` 子目录部署。
- 如不再使用自定义域名，删除 `public/CNAME`，并清除 Pages 设置中的 Custom domain，使用 `https://una539.github.io/seats/`。

## 使用

1. 导入 UTF-8 TXT 名单，每行一个姓名；空行会忽略，同名学生拥有独立 ID。再次导入会确认替换名单，并清空安排、保留布局。
2. 默认布局为 7 行 8 列，第 2、6 列后各有一条纵向过道。
3. 点击待安排学生，再点击空座位。点击已占用座位并确认，可取消安排。
4. 切换到「编辑布局」，调整行列（1–20）、点击空座位禁用或恢复、点击左侧列间边界添加或移除过道。已占用座位不可禁用，缩小布局不能移除已占用位置。
5. 「随机安排剩余学生」仅分配待安排学生，保留手动安排。座位不足时不执行；随机完成后可一步撤销，其他数据操作会结束此次撤销机会。
6. 导出 Excel 为讲台视角：行列均翻转，姓名方向不变，门左窗右，讲台在下，连续过道合并显示。页面始终保持学生视角。

状态自动保存至当前浏览器的 localStorage。更换浏览器、清除网站数据或使用隐私模式可能导致记录丢失；Excel 是打印导出，不是可重新导入的备份。多人共用电脑时请注意本地学生名单的隐私。建议只打开一个操作标签页。

## 偏好规则随机排座

先导入 TXT 名单，再点击随机安排按钮右侧的导入图标，选择 JSON 文件：

```json
{
  "version": 1,
  "rules": [
    { "type": "apart", "students": ["张三", "李四"] },
    { "type": "together", "students": ["王五", "赵六"] }
  ]
}
```

- `apart` 尽量拉大空间距离；`together` 优先同排直接相邻且无过道，否则尽量靠近。横向距离将每条过道按一个座位宽计入。
- 规则只通过唯一姓名匹配学生 ID；未知姓名、重名、自身配对、格式错误和不支持的规则会逐条忽略，不影响合法项。同类型的重复配对只计算一次。
- 每次成功读取有效 JSON 后替换旧规则，仅短暂显示「导入成功」；无法解析或读取文件时静默保留旧规则。
- 规则独立于座位数据，仅在当前页面会话内保留。刷新页面后需重新导入；替换 TXT 名单时会清除旧规则。
- 随机优化只调整本次随机学生，包括与剩余空位交换，不移动此前已安排的学生。所有规则均为软偏好，冲突或不可满足时仍正常排座。
- 无规则时沿用原随机算法。优化最多 6000 次尝试，设约 120ms 时间预算并分批让出主线程；仍支持撤销本次随机安排。

## 代码结构

- `src/lib/model.ts`：数据类型、名单解析、手动/随机分配、尺寸保护、持久化校验。
- `src/lib/export.ts`：独立的讲台视角坐标映射与 Excel 导出。
- `src/lib/preferences.ts`：规则解析、含过道的距离评分和受限交换优化。
- `preferences.test.ts`：规则容错、评分、固定座位保护及优化不变量测试。
- `src/App.svelte`：左右分栏界面及交互。
- `src/app.css`：新拟物样式与桌面自适应。
- `model.test.ts`：52 人验收流程、同名处理、异常保护、Excel 镜像及文件回读测试。

右侧空间不足时座位区可滚动；没有添加移动端专用模式、后端或其他排座条件。
